# NOLA EDITION — Archive 001 Website

This is a static GitHub Pages website built for NOLA EDITION's current Florida P / Reunion focus.

## Included
- `index.html` — luxury editorial homepage
- `shop.html` — four current Square purchase links
- `archive-001.html` — Archive 001 / Florida P story page
- `story.html` — NOLA EDITION brand story
- `styles.css` — responsive luxury editorial design system
- `script.js` — mobile navigation, scroll effects, and November 17 countdown
- `assets/archive-001-jersey.png` — current visual used in the site
- `CNAME` — keeps `nolaedition.com` configured for GitHub Pages
- `404.html`, `robots.txt`, `sitemap.xml`

## Publish on GitHub Pages
1. Back up your current repository first.
2. Upload all files and the entire `assets` folder to the repository root.
3. Replace the old site files when GitHub asks.
4. Keep the included `CNAME` file at the repository root.
5. Commit the changes.
6. In GitHub: **Settings → Pages** and confirm the same branch/folder you currently publish from.
7. Open `https://nolaedition.com` after the deployment finishes and test all four Square checkout buttons on mobile.
